# Sales Data Analysis using SQL

## Objective
To analyze sales data and find revenue insights, top customers, and product performance.

## Tools Used
- MySQL workbench
- SQL (SELECT, WHERE, GROUP BY, HAVING, SUM, COUNT, AVG)

## Dataset
Table: sales  
Columns: order_id, customer_name, city, product, amount

## Business Questions Solved
- Total revenue generated
- City-wise sales
- Top customer by spending
- Cities where laptop sales > 50000
- Number of products sold per city

## Key Insights
- Pune generated the highest revenue
- Asha is the top customer
- Laptop is the highest revenue product
- Mumbai and Pune have high laptop sales
